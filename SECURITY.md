# Security policy

## Supported versions

InstallGate has not published a release. Security fixes currently target the latest `main` branch.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not open a public issue for a suspected vulnerability or include live credentials, weaponized payloads, or sensitive package data in a report.

Include the affected commit, impact, reproduction conditions, and a minimal non-sensitive proof when possible. Receipt will be acknowledged as soon as practical, followed by an assessment and coordinated remediation plan.

## Security boundary

InstallGate is defensive software, not a guarantee that allowed packages are safe. A positive decision means the available evidence satisfied the configured policy at that time.
